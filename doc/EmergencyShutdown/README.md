EmergencyShutdown
=================

# Overview

EmergencyShutdown is a tool to shutdown remote computers in case of a power failure as fast as possible.

# Prerequisites

To use WMI to shutdown a remote computer the remote registry has to be activated on the remote computer, the firewall has to allow WMI remote access and the user needs admin permissions on the remote machine. 
See [How to Remotely Shut Down or Restart Windows PCs](https://www.howtogeek.com/109655/how-to-remotely-shut-down-or-restart-windows-pcs/) for more details. Pay attention to potential security issues!
