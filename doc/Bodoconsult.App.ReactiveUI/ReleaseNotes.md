Release notes for Bodoconsult.App.ReactiveUi
==========================


# 1.0.9

-   New package

-   Added base classes for OS independent menu generation (normal menus and context menus)

-   Added base classes for region based navigation

-   Added CopyrightViewModel used for a copyright dialog

-   Added IImageViewModel / ImageViewModel for image control showing an image and giving the user the chance to export it as bimap or copy it to clipboard

-   Added IUiFileDialogService for implementing file picker dialogs

-   Added IUiClipboardService for implementing clipboard services
